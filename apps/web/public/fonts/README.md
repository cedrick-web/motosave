# Licensed web font assets

Add the Gopher WOFF2 files obtained under a valid web license from Adam Ladd Design:
- Gopher-Regular.woff2
- Gopher-Medium.woff2
- Gopher-Bold.woff2

The CSS already references these files. Font binaries are intentionally not committed without a license. Until supplied, the browser falls back to Inter and the system UI fonts.
